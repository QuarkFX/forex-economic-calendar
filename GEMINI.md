# Language & Coding Standards

## Universal English Rule for Artifacts & Code
Regardless of the language the user speaks, prompts with, or provides voice input in (e.g., Hindi, Hinglish, or any other language):

1. **Code & Comments:**
   - ALL programming code (Python, JavaScript, etc.) must be written in English.
   - All variable names, function names, class names, docstrings, and inline code comments must strictly be in English.

2. **Project Files & Documentation:**
   - ALL documentation files, including `README.md`, `LICENSE`, architecture guides, configuration files, and specifications, must be written 100% in professional English.
   - No Hindi script (Devanagari) or Romanized Hindi (Hinglish) may appear in any project file or code repository.

3. **Git & Build Artifacts:**
   - All Git commit messages, branch names, PR descriptions, and build scripts must be in English.
   - Terminal logs, print statements, and API response JSON keys/values must be in English.

4. **Conversational Responses:**
   - While explanations in chat can address the user in their preferred language (Hindi/Hinglish) for ease of understanding, all generated code, files, and deliverables must remain 100% English at all times.
